Show two lanes: browser above and server below. The server flow is API validation → event resolution → decision gate → permission-filtered retrieval → conflict/evidence verification → card. Place working evidence on the left and a four-row risk/response matrix on the right. Keep 41 tests and 27/27 frozen cases separate. State that results cover development fixtures, not real-world accuracy, and that live microphone rehearsal remains pending.

Compare an unchecked Friday promise with a ClashPoint-assisted, evidence-backed conflict and safer conditional wording. Add three stakeholder outcomes. Label the benefits as intended and unmeasured; do not claim time, revenue, adoption, or compliance outcomes.

### Slide 6 — RESEARCH AND REFERENCES
